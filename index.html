Voice Commands

  • "Add task: [task name]" - Add a new task
  • "Add task to [category] list: [task name]" - Add a task to a specific category
  • "Add task: [task name] by [date]" - Add a task with a due date
  • "Complete task: [task name]" - Mark a task as complete
  • "List tasks" - Hear your current tasks
  • "Start Pomodoro for [task name]" - Start a 25-minute timer
  • "Clear all tasks" - Delete all tasks from your list

Date formats: "tomorrow", "next week", "next month", or specific dates like "December 25th"
